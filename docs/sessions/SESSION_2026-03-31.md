- 순환 참조 해결: PasswordEncoder를 별도 @Configuration으로 분리
- exceptionHandling 커스텀: OAuth2 활성화 시 302 대신 403 JSON 반환
- 프론트엔드 테스트: fireEvent.change 사용 (userEvent + fakeTimers 호환성 문제)

### 이슈 및 해결

| 이슈 | 원인 | 해결 |
|------|------|------|
| frontend/.git 독립 레포 | frontend가 별도 git init | rm -rf frontend/.git, 부모 레포로 통합 |
| useRouter mock 누락 | next/navigation 미모킹 | setup.ts에 vi.mock("next/navigation") 추가 |
| SearchBar 테스트 타임아웃 | userEvent + fakeTimers 비호환 | fireEvent.change로 교체 |
| test-utils TypeScript 오류 | auth 필드 optional | auth를 required로 변경 |
| UnnecessaryStubbingException | Mockito strict stubbing | willAnswer + 조건부 반환으로 변경 |
| SecurityConfig 순환 참조 | PasswordEncoder → Security → OAuth2 → PasswordEncoder | PasswordEncoderConfig 분리 |
| 302 리다이렉트 (403 대신) | OAuth2 기본 동작 | exceptionHandling + custom authenticationEntryPoint |
