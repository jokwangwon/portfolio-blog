# 포트폴리오 공개 범위와 지원 자료 구분

작성일: 2026-09-15 · 사용자 요청: 누구나 보는 포트폴리오와 이력서/상세 기록의 범위 구분

## 기준

2026-09-29 후속: 사용자가 민원e의 담당 구현 내용을 공개 사례로 소개하도록 명시했다. 해당 설명에 한해 문제·담당 업무·기술 선택·결과를 소개하며, 회사 코드·고객 식별정보·내부 원본은 공개하지 않는다. [적용 범위와 근거](portfolio-positioning-2026-09-29.md). 아래 표는 기존 기본 범위로 유지한다.

| 위치 | 목적 | 포함할 내용 | 제외할 내용 |
|---|---|---|---|
| 공개 포트폴리오 | 어떤 일을 해 온 사람인지 빠르게 파악 | 회사명·기간·역할·한 문장 요약, 선별한 공개 개인 프로젝트, 기술 관심사·공개 학습 글 | 회사별 세부 구현 목록, 내부 의사결정 설명, 전체 업무 원장 |
| 지원용 이력서 | 지원 직무와 관련 경험을 간결하게 전달 | 경력 구간, 직무 관련 핵심 기여, 대표 프로젝트, 교육/확인된 자격 | 모든 업무의 나열, 검증되지 않은 성과, 불필요한 개인 사정 |
| 지원용 경력기술서 | 담당 범위와 문제 해결을 구체적으로 설명 | 본인 역할, 문제·선택·구현·검증·결과, 팀과 개인의 기여 구분 | 내부 원본·고객 식별정보·비공개 코드·불확실한 수치 |
| 개인 보관 | 원자료와 생각을 빠짐없이 보존 | 출처, 초안, 확인 필요 사항, 시행착오, 지원 활동 기록 | 자동 공개·외부 전송 |

회사명·기간·역할은 기존 공개 범위를 유지하는 기본안으로 적용하고, 상세 내용은 지원 자료로 이동했다. 회사명도 숨길지 묻는 선택 질문에는 추가 답변을 받지 않았으므로 이를 새 승인으로 기록하지 않는다.

## 이번 페이지 변경 기준

- 경력 세 구간과 학습 기록을 유지하되 회사별 설명은 한 문장으로 줄인다.
- 담당 업무 bullet과 회사 간 공통 프로젝트 상세 설명은 공개 데이터에서 제거한다.
- About는 업무 경험의 분야와 현재 학습/개인 개발을 소개한다.
- 공개 개인 프로젝트는 검증 가능한 대표 경험을 보여주는 근거로 유지한다.
- 상세 자료를 CSS·접기·숨겨진 탭으로 감추거나 브라우저로 보내 놓지 않는다. 공개 HTML·클라이언트 JS에 포함하지 않는다.
- 이력서/경력기술서는 Git 제외 로컬 문서로 준비한다. 공개 다운로드·비밀 URL·클라이언트 비밀번호 화면을 비공개 저장으로 간주하지 않는다.
- 기존의 상세 화면 캡처와 상세 내용을 담은 검증 스크립트도 Git 제외 위치로 옮겨 공개 저장소에 다시 포함되지 않게 한다.
- 이미 열람되거나 저장된 과거 공개본을 소급해서 회수한다고 주장하지 않는다. Git 이력 재작성이나 외부 캐시 삭제는 이번 작업 범위가 아니다.
