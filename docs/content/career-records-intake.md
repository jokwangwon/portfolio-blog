## 포트폴리오 콘텐츠로 바꾸는 기준

- 원문 자료 → 사실 목록 → 회사별 요약 → 상세 사례 → 관련 블로그 기록 순서로 정리한다.
- ‘전체 프로젝트의 기능’과 ‘본인의 기여’를 구분한다. AI가 만든 정리본 자체를 성과 증빙으로 삼지 않는다.
- 홈에서는 주요 경험을 쉽게 읽게 하고 회사별 상세에서 전체 업무 목록과 개별 기록을 연결한다.
- 개인 공부와 회사 업무를 뒤섞어 소속이나 경력을 확대하지 않는다.
- 현재 미재직 상태를 설명하기 위해 공개 페이지에 불필요한 상태 배지를 추가하지 않는다. 과거형과 종료 기간을 정확히 사용한다.
