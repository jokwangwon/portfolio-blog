# 이미지 첨부 저장·조회 설계

2026-09-15 · 사용자 승인: 이미지 파일을 별도 영속 저장하고 DB에서 글과 연결하며 공개 범위를 함께 적용한다.

구현·검증 완료: [결과 보고서](../review/image-attachments-2026-09-15.md). 향후 이력/AI 분석 작업과 분리해 먼저 적용했다.

## 계약

- PNG/JPEG 파일당 10MiB 이하, 한 변 8192px 이하, 총 20,000,000픽셀 이하. 실제 파일 판독으로 검사하고 재인코딩해 파일 메타데이터를 제거한다. 재인코딩 결과도 10MiB 제한. SVG/GIF/WebP는 첫 구현에서 지원하지 않는다.
- `POST /api/portal/attachments`: multipart `file`, 인증 사용자(운영 ADMIN). `{id,url,mediaType,byteSize,width,height}` 반환. url은 `/api/portal/attachments/{UUID}`.
- `GET /api/portal/attachments/{UUID}`: 작성자 또는 연결된 글이 미삭제/PUBLISHED/PUBLIC인 경우만 이미지 바이트 반환. 그 외 404. `Cache-Control: no-store`, `X-Content-Type-Options: nosniff`.
- 업로드 직후 attachment는 작성자 소유의 미연결 상태다. 새 글 저장 전에도 미리 볼 수 있고 방문자는 접근할 수 없다.
- 글 저장 트랜잭션에서 실제 Markdown/HTML 이미지 참조를 파싱해 첨부 행 잠금 후 연결한다. 코드 블록/인라인 코드의 예시 주소는 연결하지 않는다. 타인 소유 또는 다른 글에 이미 연결된 파일은 400으로 거부한다. 본문에서 제거한 첨부는 연결만 해제해 즉시 작성자 전용으로 되돌린다.
- 본문에는 UUID 참조만 남긴다. 비공개 파일은 정적 public 폴더에 두지 않는다. 인증 쿠키 정책은 확대하지 않고 UI가 정확히 검증한 첨부 UUID만 Bearer 인증으로 조회해 화면용 Blob URL을 생성한다. 외부 이미지 URL에 토큰을 보내지 않는다.
- 화면용 Blob은 본문/복구본에 저장하지 않는다. 로그아웃·인증 만료·URL 변경·화면 이탈 때 요청 취소 및 URL 해제, 늦은 응답 폐기를 수행한다.

## DB·파일 수명

`attachments`: UUID PK, owner_id FK, nullable post_id FK, storage_key(UUID 확장자), media_type, byte_size, width, height, sha256, created_at. 파일명은 사용자 입력으로 경로를 만들지 않는다.

파일은 api-server 전용 영속 볼륨에 보관한다. 파일 생성 뒤 DB 저장 실패 시 새 파일을 제거한다. 글 저장 실패는 연결 변경과 본문 변경을 함께 롤백한다. 제거/실패한 미연결 파일은 브라우저 복구를 위해 우선 보존하고 자동 만료 삭제는 별도 정책으로 둔다. 글 삭제 시 공개 조회는 즉시 차단한다.

DB 백업과 첨부 볼륨 백업을 함께 보관한다. 새 파일은 변경 불가능하게 저장하므로 DB 덤프 후 파일 아카이브를 만들면 덤프에 참조된 파일을 포함할 수 있다(이 단계에서 파일 자동 삭제 없음). 정기 자동 백업·외부 복제는 별도 운영 작업이다.

## 작성 흐름

이미지 추가 버튼/붙여넣기/드래그가 공통 업로드 경로를 사용한다. 진행과 오류를 표시하고 업로드 중 편집·저장을 잠가 삽입 위치 경쟁을 막는다. JPEG 방향은 브라우저에서 정규화한다. 저장 실패 시 본문/복구본을 유지한다.

이전 data URL 이미지는 명시적인 글 저장 때만 업로드와 URL 변환을 수행한다. 실제 이미지 참조만 변환하고 코드 예시는 보존한다. 변환이나 글 저장 실패 시 기존 본문을 지우지 않는다. 운영 글을 일괄 재작성하지 않는다. 서버는 실제 이미지 위치의 data/blob URL이 새로 영속 저장되지 않도록 검사한다.

## 검토·검증

3+1 검토: 원자적 첨부 연결, 동적 공개 권한, 외부 이미지 토큰 차단, 파일/픽셀 제한, 브라우저 삽입 경쟁, 파일 백업을 보완했다. 별도 인증 쿠키/브로커/외부 저장 서비스는 추가하지 않는다.

필수: 정상 PNG/JPEG, 손상/위장/SVG/용량/치수 거부, 미연결 owner-only, 공개/비공개/제거/삭제, 다른 소유자·다른 글 연결 거부와 롤백, 동시 연결, 편집/미리보기/읽기 표시, 외부 토큰 미전송, 업로드·글 저장 실패 복구, 구형 이미지 변환·코드 예시 보존, 로그아웃 Blob 차단, 재시작·백업/복원. 운영 반영 전 DB/파일 백업, 백엔드 먼저 배포, 새 편집 화면 배포 후 실제 HTTPS 확인.
