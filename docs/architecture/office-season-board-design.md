# Office 계절 테마와 작업 칠판

2026-09-15 사용자 요청에 따른 기존 Office 확장. [출퇴근 설계](office-presence-design.md)의 공개 경계와 출퇴근 동작을 유지한다.

- 한국 시간(Asia/Seoul)의 달력 기준: 봄 3–5월, 여름 6–8월, 가을 9–11월, 겨울 12–2월.
- 30초마다 날짜 확인, 탭으로 돌아올 때 즉시 갱신. 월/연도 경계도 페이지 새로고침 없이 반영한다.
- 기본 자동 테마. 방문자는 현재 화면에서만 다른 계절을 미리 볼 수 있으며 실제 날짜·작업 상태는 변하지 않는다. 새로고침하면 자동.
- 코드 기반 픽셀 창밖 풍경(벚꽃/녹음/단풍/눈), 계절색 프레임과 실내 소품. 기존 캐릭터/가구를 가리지 않고 소등 시 실내 장식도 어두워진다. 실제 날씨를 의미하지 않는다.
- 데스크톱은 사무실과 칠판을 나란히, 모바일은 칠판을 아래 배치. 칠판은 텍스트로 렌더링해 접근성과 긴 제목 줄바꿈을 보장한다.
- 칠판에는 현재 연결된 세션의 공개 제목, 도구 종류, 작업 상태만 표시한다. 빈 사무실/방송 꺼짐/연결 장애에서 이전 제목은 남기지 않는다.
- 공개 스키마에 선택적 publicTitle 추가. 최대 48 Unicode 코드포인트, 일반 문자·숫자·공백·기본 문장부호만 허용. 입력에서 자동 추출하지 않는다. 지정되지 않거나 유효하지 않으면 일반 작업 상태로 대체한다.
- 명령 래퍼 --public-title 및 Claude 실행 환경 OFFICE_PUBLIC_TITLE로 명시 지정한다. Hook의 prompt/tool_input/파일명/명령은 제목으로 사용하지 않는다.
- 제목은 작성자가 공개하기로 선택한 내용이다. 형식 검증은 기밀 판별이 아니며 자동 비식별화를 보장하지 않는다.
- 테스트: 서울 날짜/계절 경계, 공개 제목 검증·원문 미수집·하위 호환, 칠판 상태/긴 제목/연결 장애, 4계절·모바일·소등과 기존 출퇴근.

별도 DB/공개 쓰기 API는 추가하지 않는다.

## 진단 후 보완 (2026-09-15, 사용자 승인)

가로 SVG 배너를 제거하고 같은 Canvas의 벽에 계절 창문을 그린다. 실내와 동일한 픽셀 배율/이동을 적용하고 가구·통행 공간을 가리지 않는다. 서울 시간 06:00~18:59는 낮, 그 외는 밤으로 표현하며 출근 여부는 실내 조명에만 반영한다. 실제 일출/일몰/날씨를 의미하지 않는다. 30초와 탭 복귀 때 낮/밤 갱신.

바닥은 저대비 목재·중성색, 소파 등은 저채도 포인트 색으로 통일한다. 캔버스 바탕과 칠판 목재 프레임도 같은 계열로 맞춘다. 정수 픽셀 크기로 장면을 렌더링하고 작은 화면에서는 전체 지도가 맞도록 맞춤 배율/복귀 기능을 제공한다. 소등 덮개를 낮춰 방·가구 윤곽을 유지한다. 칠판 문자는 HTML 가독성을 유지한다.

## 계절 인지성 강화 (2026-09-15, 사용자 요청)

계절별 창문·작은 소품만으로 구분이 약하다는 피드백에 따라 동일한 픽셀 장면에서 벽·휴게실 바닥·소파·러그·전면 정원 색상을 함께 바꾼다. 봄은 벚꽃/크림/연분홍, 여름은 녹음/청록/라탄, 가을은 단풍/호박/테라코타, 겨울은 눈/청회/따뜻한 목재. 업무실 책상·캐릭터·작업 동작은 유지한다. 장식은 충돌 맵이나 좌석 수를 바꾸지 않는다.

정원은 실내 밖 하단에 별도 24 원본 픽셀 높이를 확보한다. 맞춤/히트 테스트는 정원을 포함한 장면 높이를 사용한다. 러그와 낮의 창가 빛은 가구·캐릭터 아래, 창문은 벽의 깊이 순서에 그린다. 실내에 눈/낙엽을 흩뿌리지 않는다. 추가 반복 애니메이션 없이 계절 자체의 색·형태를 강조한다. 칠판 텍스트 가독성은 유지하고 목재 프레임/외곽색만 계절 팔레트와 통일한다. 계절 선택은 방문자 미리보기이며 출퇴근·실제 서울 시각과 독립이다.

검증: 4계절/낮밤/소등/모바일/선택·맞춤 좌표 일치, 장식 전후 기존 레이아웃·가구 좌표 불변, 반복 전환 색상 캐시 및 콘솔 오류 없음.

## 한 명 작업 시 생활감 (2026-09-15, 사용자 추가 요청)

사용자가 장식 인원 또는 상호작용을 제안했다. 선택 질문 후 기본안으로 장식용 고양이와 소품 반응을 우선 구현한다. 실제 세션 수·칠판·조명에는 영향을 주지 않는다. 고양이는 가구와 분리된 장식 상태로 휴게실 아래의 짧은 경로를 다니며, 작업이 없거나 연결되지 않으면 방석에서 쉰다. 고양이 쓰다듬기/커피 내리기를 Canvas 클릭과 명시적 키보드 버튼 양쪽으로 제공한다. 상호작용은 방문자 화면에서만 지속되며 서버 저장/소리/외부 호출 없음. prefers-reduced-motion에서는 이동을 멈추고 정적인 반응만 표시한다.

## 정원·창문 도트 밀도 보완 (2026-09-15)

실내 화분/가구에 비해 하단 나무와 창문이 단순하다는 사용자 피드백을 반영한다. 동일한 원본 픽셀 크기를 유지하며 수관의 불규칙 윤곽·잎 덩어리·6단계 명암·가지/줄기·접지 그림자를 함께 표현한다. 창문은 같은 계절 팔레트의 작은 나무와 먼 숲/하늘 층을 사용한다. 정원은 잔디·꽃/낙엽·화단 경계석·포장길의 단차를 저대비로 추가한다. 픽셀 노이즈나 추가 애니메이션은 사용하지 않는다. 고정 장식은 계절/낮밤별 캐시로 렌더링하며 기존 정원 높이·통로·출근/상호작용 좌표를 유지한다. 검증은 4계절 낮밤 실제 화면과 모바일·기존 동작 회귀 확인을 중심으로 한다.

사용자가 추가 제작 이미지 전체(고양이·화분 등)로 수정 범위를 넓혔다. 기존 배포된 원본 가구 자산을 기준으로 고양이의 윤곽/무늬/웅크린 자세, 바구니의 곡면과 직조, 계절 탁상 소품의 화분 테두리/입체 명암, 러그의 얇은 테두리/직조를 함께 수정한다. 원본 이미지 파일은 유지하고 신규 장식의 코드 스프라이트만 교체한다. 출근과 고양이 이동 경로/상호작용은 유지한다.

## 정원 제거 및 실내 조화 (2026-09-15, 현행 기준)

사용자가 하단 정원 제거를 요청했다. 기존 정원 24px 확장·그리기·테마 필드/설명은 제거하고 사무실 원래 336×208 좌표/맞춤 비율로 돌아간다. 이 절은 위 정원 관련 이전 설계를 대체한다. 계절 창밖 나무는 유지한다.

도트가 따로 보이는 원인은 강한 휴게실 바닥색, 소파의 중복 색상 보정으로 압축된 명암, 고양이의 접지 그림자 부족, 장식마다 다른 목재/윤곽 색이다. 공통 목재·저채도 바닥으로 실내를 연결하고 계절감은 창문·소파·러그/소품에 남긴다. 소파 명암을 복원하고 고양이 그림자, 공통 장식 목재/윤곽 재질을 적용한다. 원본 가구 PNG와 레이아웃은 유지하며 출근·히트 테스트/맞춤·고양이 상호작용이 회귀하지 않는지 확인한다.

## 창문·계절 소품 재평가 (2026-09-15, 현행 보완)

창문이 풍경 액자처럼 보이고 호박 등 계절 아이콘이 공간과 어긋난다는 피드백을 반영한다. 48×24의 낮은 4분할 풍경 프레임은 벽 높이에 맞춘 위아래 벽 여백을 남긴 48×28 두 칸 창으로 교체한다. 두 나무를 나란히 완결된 아이콘으로 배치하지 않고 하나로 이어지는 낮은 원경과 가장자리로 들어온 가지를 통해 창밖 일부만 보이게 한다. 창틀 안쪽 음영·유리 반사·창턱 단차로 벽의 개구부임을 표현한다. 해/달/별 아이콘과 가로 중간 창살은 제외한다. 낮/밤은 풍경 밝기와 하늘색으로 구분한다.

호박/스노글로브/선인장의 서로 다른 계절 아이콘 대신 동일한 작은 도자기 화병에 봄 꽃·여름 잎·가을 마른 가지·겨울 열매를 꽂는다. 겨울 소품에도 눈을 실내에 얹지 않는다. 원본 SMALL_TABLE_FRONT는 상판이 이미지 y=11~24이므로 장식의 바닥을 가구 y=160 기준 177~178에 놓아 상판 안에 닿게 한다. 이전 소품은 y=171(상판 뒤쪽 경계)에 붙어 떠 보였다. 창문/소품 외 요소와 정원 제거 상태는 유지한다.

## 각진 고양이와 Office 다크 모드 (2026-09-15)

사용자가 고양이 도트만 조금 더 사각형 느낌으로 바꾸고 페이지 전반의 다크 모드를 개선하도록 요청했다. 고양이의 크기/팔레트/위치/이동/클릭은 유지하며 머리·몸통·귀/발의 계단형 곡선을 직선 위주로 정리한다. 다른 가구/창문/화병 형태는 유지한다.

기존 Office 다크 모드는 밝은 계절 벽색을 48% 혼합한 회갈색 카드에 회색 보조 문자를 올려 대비가 부족했다. Office 범위의 표면/테두리/본문/보조/강조/버튼/칠판 재질 토큰을 라이트·다크로 분리한다. 캔버스는 다크에서 눈부심을 소폭 줄이되 출근/소등·서울 낮밤은 UI 테마와 별도로 유지한다. 작은 안내 글씨 크기·행간과 키보드 포커스도 보완한다. 실제 헤더 테마 버튼과 새로고침 유지, 4계절·0/1명·모바일·다크 텍스트 대비를 검증한다.

사용자가 고양이가 가만히 있지 않고 돌아다니기를 추가 요청했다. 고양이는 출근/연결/소등과 독립적으로 휴게 공간 가장자리를 산책한다. 한 바퀴 후 바구니에서 4초 쉬고 재출발하며 중간 정지는 짧게 한다. 쓰다듬기 반응 중에는 멈추고 이후 계속 걷는다. 사용자 동작 줄이기 설정에서는 바구니에 머문다. 이 규칙은 앞선 '작업이 없으면 항상 잠듦' 규칙을 대체한다. 이동 경로가 벽/빈 타일에 들어가지 않는지 실제 레이아웃 기반 테스트로 확인한다.

## 고양이 외곽선 비중 보완 (2026-09-15)

각진 실루엣과 22×18 정수 픽셀 크기를 유지하되, 털색 경계로 등·머리 윗면을 연결한다. 귀·발·꼬리의 양면 어두운 테두리를 줄이고 내부 털 면적을 늘린다. 가장 짙은 윤곽은 배 아래·발바닥 등 접지/겹침에 한정하며 눈·코의 식별성은 유지한다. 서기·걷기 두 프레임·쓰다듬기·수면 모두 동일한 기준을 적용한다. 이동/상호작용/출근 및 공통 가구 재질은 변경하지 않는다. 검증은 확대 스프라이트와 실제 라이트/다크·소등 화면 비교로 수행한다.

## 개인 작업실로의 위치 정리 (2026-09-15)

사용자 승인: 채용 포트폴리오는 경험·프로젝트 결과 중심, 블로그는 개발·공부·독서 기록, Office는 개인 작업실로 구분한다. 기존 /office 주소는 유지하며 제목·메타데이터를 작업실로 변경한다. 포트폴리오/블로그의 전역 메뉴는 포트폴리오·기록·작업실을 제공한다. 포트폴리오 페이지 내부에는 프로젝트·경력·소개로 가는 별도 탐색을 유지한다.

작업실은 연결한 AI/로컬 작업의 현재 활동을 표현한다. 세션 종료와 프로젝트 완료를 구분하고, 완료 관리/장기 이력 기능이 존재하는 것처럼 소개하지 않는다. 칠판에서 같은 페이지의 프로젝트·기록 영역으로 이동한다. 아래에는 기존 공개 프로젝트 목록과 공개 글 목록 API의 최근 글을 제공한다. 특정 세션과 글의 관계를 제목으로 추측하지 않는다. 빈 글 목록·조회 실패·재시도 상태를 구분한다. 방문자 쓰기나 수집 정보/공개 계약은 변경하지 않는다.

검증: 홈/기록/작업실 상호 이동, 모바일 메뉴·키보드, 칠판 앵커 이동, 최근 글의 로딩/빈 목록/실패/정상 목록, 라이트/다크와 모바일, 기존 출퇴근·상호작용.

## 프로젝트 칠판 중심 구성 (2026-09-15, 현행)

사용자 피드백에 따라 장문 소개·세션 해설·전체 프로젝트/최근 글 모음을 제거하고 작업실 제목과 픽셀 사무실·칠판만 표시한다. 칠판은 프로젝트 루트명 아래 현재 업무를 묶고, 유휴 상태에서는 최근 프로젝트/마지막 활동 시각을 표시한다. 기록과 포트폴리오 링크는 칠판 하단에 유지한다. 이 절이 직전의 프로젝트·최근 글 모음 영역 설계를 대체한다. 데이터 범위/최근 기록 보존은 [출퇴근 설계](office-presence-design.md)의 프로젝트 확장을 따른다.
