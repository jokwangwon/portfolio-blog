# Office 디자인·출근 표시 진단 — 2026-09-15

사용자 요청에 대한 읽기 전용 진단. 이 점검에서는 운영 화면/수집기 코드를 변경하지 않았다.

## 출근 없음의 원인

수집기 서비스 active, 방송 enabled=true지만 sessions=[]였다. 현재 Codex 작업이 기존 Claude Hook/명령 래퍼에 연결되지 않은 상태다. 서버 가동과 실제 작업 세션 감지는 별개이며, 사용자 의도인 현재 Codex의 자동 출근은 미완성이다.

설치된 CLI의 App Server 프로토콜을 생성해 thread/list의 런타임 active/idle 상태와 cwd 필터, useStateDbOnly 지원을 확인했다. 하지만 기존 데몬 제어 소켓이 없어 codex app-server proxy / daemon version 연결은 실패했다. 실행 중인 앱을 재시작하거나 새 데몬을 만들지 않았다. 대화 원문/세션 로그 조회, 임의 출근 등록도 하지 않았다. 추가 연결 구현 시 실제 실행 환경에 맞는 생명주기 이벤트가 필요하다. 프로세스가 켜져 있다는 사실만으로 작업 중이라고 판단해서는 안 된다.

## 상단 이미지

SeasonWindow.tsx의 SVG로 만든 계절별 창밖 풍경이다. 나무, 벤치, 먼 건물, 해/달을 표현한다. 잘못 로드된 외부 이미지가 아니다.

- 실내는 위에서 내려다본 시점인데 상단 풍경은 정면 시점이며 별도 HTML 영역에 있어 공간이 이어지지 않는다.
- SVG viewBox 480×88과 가로로 긴 고정 높이 영역의 비율이 다르고 preserveAspectRatio=xMidYMid slice로 위아래가 잘린다. 나무·벤치·해/달의 형태가 불완전해진다.
- 실내 에셋보다 큰 도트와 단순한 색면으로 그려져 다른 작품처럼 보인다.
- resting={empty}로 출근 인원 0을 밤 풍경에 연결했다. 실제 시각이 아니라 인원으로 낮/밤을 바꾸는 설계다.

## 실내 진단

1. 갈색 업무실, 파란 휴게실, 자주색 소파, 흑백 체크 바닥의 대비가 강하다. 캐릭터/작업보다 바닥과 가구의 구획이 먼저 눈에 들어온다.
2. 반복 타일의 경계와 촘촘한 패턴이 격자처럼 두드러진다. 소수 배율(확인 화면 약 2.02배)에서 개별 픽셀을 소수 좌표 fillRect로 그리는 방식도 도트 경계 불균일을 만들 수 있다. 텍스처와 렌더링을 각각 확인해 정리해야 한다.
3. 실내 PNG/Canvas, 상단 SVG, 부드러운 CSS 칠판 사이의 픽셀 크기·질감이 통일되지 않았다. 칠판의 읽기 쉬운 텍스트는 유지하되 프레임·색조를 실내에 맞추는 편이 좋다.
4. 소등은 장면 위에 72% 어두운 색을 덮는다. 밝은 페이지 배경과 큰 칠판에 비해 실내가 지나치게 묻혀 사무실보다 어두운 빈 영역으로 보인다.
5. 사계절 변화는 현재 창밖/프레임/작은 소품에 집중되어 있고 실내 주조색은 고정이다. 방 전체에 계절 분위기가 통합된 수준은 아니다.

## 권장 순서

1. 실제 Codex 생명주기 연결과 출근 표시부터 보완.
2. 상단 배너를 제거하거나 실내 벽의 작은 창문으로 재구성. 인원과 낮/밤 분리.
3. 바닥·벽 팔레트를 저채도 목재/중성색으로 통일하고 포인트 색을 제한.
4. 도트 확대·타일 경계 정리, 소등 때 방 윤곽과 가구 구분 유지.
5. 통일된 실내 팔레트 위에 계절별 창밖·소품·조명을 얹기.

## 승인 후 보완 진행

진단 이후 사용자 승인으로 구현했다. Codex 공식 Hook 어댑터와 프로젝트 설정을 추가했고 단위 테스트 18개를 통과했다. 실제 대화 자동 출근은 Codex 자체 /hooks 신뢰 검토 후 다음 요청에서 확인해야 한다. 현재 실행 중 대화를 수동으로 출근시키지 않았다.

SVG 배너를 제거하고 기존 Canvas 벽에 48×24 픽셀의 계절 창문을 통합했다. 실내 원본 픽셀에서 한 번 렌더링 후 확대해 타일 틈을 제거하고 히트 테스트도 동일 좌표계를 사용한다. 자동 맞춤은 가능한 정수 배율을 사용하며 모바일에는 축소/전체 보기 복귀를 제공한다. 모바일 화면 전환 중 0 크기 Canvas가 생기는 경계 조건을 추가로 보호했다. 바닥·벽은 목재/중성색, 소파는 저채도 녹색, 흑백 체크는 중성 바닥으로 교체했다. 소등 덮개는 72%에서 38%로 조정했다.

서울 시각으로 창밖 낮/밤을 구분하며 출근 여부와 분리했다. 확대 조작부는 모바일 창문을 가리지 않도록 장면 아래에 배치했다. 최종 검증/운영 이미지는 같은 날짜 세션 로그와 [릴리스 기록](assets/2026-09-15/office-refinement/release.json)을 참조한다.
